**Vela Bay** — a sun-soaked open-world crime game in one browser tab: steal cars, outrun the stars, take courier jobs, and keep the case moving.

Open `game/index.html` in a desktop browser to play offline. Follow yellow markers to start a courier run or shakedown. Your cash and mission progress autosave.

| Input | On foot | Driving |
| --- | --- | --- |
| WASD | Move | Throttle, brake, steer |
| Mouse / left click | Aim / fire | |
| Space | Sprint | |
| F | Enter parked car | Exit |
| E | Hold at a driver's door to carjack | Exit |
| Esc | Pause | Pause |

Run `node scripts/smoke.mjs` to exercise the simulation. After editing the ES modules, run `node scripts/build-offline.mjs` to refresh the file-URL build.
